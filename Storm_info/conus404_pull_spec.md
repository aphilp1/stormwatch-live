# CONUS404 Pull Spec — 4 km Terrain-Resolving Wind (Claude Code, runnable)

**Dataset:** CONUS404 (`conus404-hourly`), 4 km WRF v3.9.1.1 dynamically downscaled
from ERA5, hourly, Oct 1979–Sep 2021. Covers all four events (Camp Nov'18, Tubbs
Oct'17, Thomas Dec'17, Kincade Oct'19).

**Why this over raw ERA5:** ERA5 is 28 km (won't resolve terrain). CONUS404 already
did the ERA5→4 km WRF downscaling — it's a terrain-resolving wind field generated by
the same WRF physics we'd otherwise run by hand. Use it as the high-resolution
synoptic-to-mesoscale field; it sits between ERA5 (too coarse) and WindNinja sub-1km.

**Access:** cloud Zarr via the HyTEST intake catalog. Lazy/subsetting — no petabyte
download, and the cloud (S3) path needs no RDA login. Confirm the catalog URL against
the HyTEST changelog before running (the intake catalog URL is the one thing that
drifts; everything else below is stable).

---

## CRITICAL gotchas (read before running)

1. **Curvilinear grid.** CONUS404 is on a Lambert Conformal WRF grid. Coordinates are
   2D: `lat(south_north, west_east)` and `lon(south_north, west_east)`. You CANNOT do
   `ds.sel(lat=..., lon=...)`. Subset by finding nearest grid indices via the 2D
   lat/lon (code below), or use the HyTEST point-selection / regrid notebooks.
2. **Winds are WRF native.** `conus404-hourly` is a `wrfout` subset. Expect 10 m winds
   (`U10`, `V10`) directly. Full 3D winds on model (eta) levels may or may not be in
   this Zarr subset — CHECK `ds` variables first. If 3D u/v are present they're on
   staggered grids (`U` on west_east_stag, `V` on south_north_stag) and need
   destaggering before use. For a first pass, **use U10/V10** (10 m) — that's the
   direct analog to RAWS 20-ft winds and to WindNinja's output height.
3. **700 hPa is not a native coordinate.** WRF is on terrain-following eta levels. To
   get a 700 hPa wind you must interpolate using geopotential — only do this if 3D
   fields are in the store. For the BC/timing work, 10 m winds are the more directly
   useful field anyway; treat any 700 hPa extraction as secondary.
4. **Units.** WRF winds are m/s. Convert to mph (×2.23694) to match the pipeline's
   convention. Direction = met convention (FROM), via atan2 on u/v — use the
   pipeline's `vec_avg`, never average raw degrees.

## Step 2 — California bounding-box subset on the curvilinear grid

```python
# California domain covering all four fires
LAT_MIN, LAT_MAX = 35.0, 42.0
LON_MIN, LON_MAX = -124.0, -117.0

lat2d = ds["lat"].values            # or ds["XLAT"]
lon2d = ds["lon"].values            # or ds["XLONG"]

# boolean mask of cells inside the box, then crop to the index bounding box
inside = (lat2d >= LAT_MIN) & (lat2d <= LAT_MAX) & \
         (lon2d >= LON_MIN) & (lon2d <= LON_MAX)
jj, ii = np.where(inside)           # south_north (j), west_east (i)
j0, j1 = jj.min(), jj.max() + 1
i0, i1 = ii.min(), ii.max() + 1

ds_ca = ds.isel(south_north=slice(j0, j1), west_east=slice(i0, i1))
```

## Step 3 — slice the four event windows (UTC; mind DST)

```python
# windows in UTC. Local→UTC: PST = +8h, PDT = +7h.
```

## Step 4 — wind speed / direction (mph, met convention)

```python
MS_TO_MPH = 2.23694

def speed_dir(u, v):
    spd = np.sqrt(u**2 + v**2) * MS_TO_MPH
    # meteorological FROM-direction
    drc = (270.0 - np.degrees(np.arctan2(v, u))) % 360.0
    return spd, drc

for name, sub in subsets.items():
    spd, drc = speed_dir(sub["U10"], sub["V10"])
    sub["wspd_mph"] = spd
    sub["wdir_deg"] = drc
```

## Step 5 — extract at fire sites + domain mean (the timing re-test)

```python
# fire-site coords (verified-coordinate stations only carry full weight)
SITES = {
    "camp_jarbo":   (39.735944, -121.488944),  # NIFC-verified
    "camp_origin":  (39.794,   -121.605),       # Pulga/Poe Dam approx
    # add Tubbs/Thomas/Kincade sites from the registry as verified
}

def nearest_cell(sub, lat0, lon0):
    lat2d = sub["lat"].values; lon2d = sub["lon"].values
    d2 = (lat2d - lat0)**2 + (lon2d - lon0)**2
    j, i = np.unravel_index(np.argmin(d2), d2.shape)
    return j, i

# timing series: fire-site point vs domain-mean, per event
for name, sub in subsets.items():
    dom_mean = sub["wspd_mph"].mean(dim=("south_north", "west_east"))
    print(f"\n{name} domain-mean wspd (mph) over window:")
    print(dom_mean.to_series().describe())
    # point extraction example (Camp):
    if name == "camp":
        for site, (la, lo) in SITES.items():
            if not site.startswith("camp"):
                continue
            j, i = nearest_cell(sub, la, lo)
            ts = sub["wspd_mph"].isel(south_north=j, west_east=i).to_series()
            print(f"  {site}: peak {ts.max():.1f} mph at {ts.idxmax()}")
```

## What to do with it (ties to the plan)

1. **Timing re-test (priority).** CONUS404 is continuous reanalysis — no HRRR
   forecast-truncation. Re-run the Camp "rising vs declining limb at ignition"
   question on the 10 m field. Pre-register the expectation (Mass 2021: sunrise
   peak). Apply the domain-mean-vs-point + propagation-geometry checks that killed
   the Tubbs antisymmetry — a point leading the mean is geometry until a control on
   the same axis proves terrain.
2. **4 km BC characterization.** CONUS404 gives a terrain-aware mesoscale wind around
   each fire — a better BC envelope for WindNinja than a single coarse value, and an
   independent cross-check on the ERA5/HRRR BC.
3. **Surrogate / confidence-engine fuel.** CONUS404 4 km fields → candidate inputs for
   BC ensembles feeding `confidence_field.py`. Obs-independent.

**Still does NOT close the coupling test.** CONUS404 at 4 km is finer but still a
model, not surface observation. The held-out RAWS validation (Colby/Saddleback) and
the lidar coupling data remain the gated critical path. CONUS404 strengthens the
input/model side; it does not substitute for ground truth.
